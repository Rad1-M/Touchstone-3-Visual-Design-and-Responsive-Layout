# 🎨 Part 1: Touchstone 3 - Visual Design and Responsive Layout

## 📌 عن المشروع (باللغة العربية)
هذا المشروع هو تطبيق عملي لواجب دراسي (**Touchstone 3: Visual Design and Responsive Layout**) لبرنامج تطوير الويب[cite: 1]. يقدم المشروع موقعاً إلكترونياً متجاوباً ومتناسقاً لمخبز **North Star Bakery**[cite: 1, 2]. يركز العمل على تطبيق قواعد التصميم المرئي (CSS)، وتنسيق الهيكل التجاوُبي (Responsive Layout)، وتنظيم العناصر بشكل يدعم تجربة المستخدم والأهداف الخاصة بالعميل[cite: 1].

### 🛠️ التقنيات المستخدمة:
* **HTML5**: لبناء هيكلية الصفحات المتعددة واستخدام العناصر الدلالية (`<picture>`, `<figure>`, `<form>`, `<fieldset>`)[cite: 1, 3, 4].
* **CSS3**: لتنسيق الألوان، الخطوط، واستخدام **Flexbox** مع **Media Queries** للتجاوب مع مختلف الشاشات[cite: 1].
* **GitHub Pages**: لاستضافة المعاينة المباشرة للمشروع[cite: 1].

### 🎨 النظام البصري للتصميم:
* **الألوان (Color Palette)**: استخدام نظام ألوان متناسق يتكون من 2 إلى 4 ألوان تعبر عن طابع المخابز الدافئ وتعزز سهولة القراءة[cite: 1].
* **الخطوط (Typography)**: استخدام خطين كحد أقصى لتسهيل التصفح السريع مع تحديد هرمية بصرية بوزن وحجم الخطوط[cite: 1].
* **التجاوب (Responsive Design)**: اتباع نهج *Mobile-First* لضمان عمل الموقع بكفاءة على الشاشات الصغرى والكبرى[cite: 1].

### 📁 صفحات الموقع:
1. **`index.html`**: الصفحة الرئيسية وتضم الترحيب، المنتجات المميزة، وتوافق الملفات الصوتية[cite: 1, 3].
2. **`products.html`**: قائمة المنتجات المصنفة (خبيز حقيقي، حلويات، كعك مخصص).
3. **`about.html`**: قصة المخبز ورؤية العمل وطاقم المخبز[cite: 2].
4. **`contact.html`**: صفحة التواصل والاستفسارات المسبقة للطلبات[cite: 1].

This project is a practical submission for **Touchstone 3: Visual Design and Responsive Layout** in the Web Development program[cite: 1]. It features a responsive and visually cohesive website for **North Star Bakery**[cite: 1, 2]. The project focuses on implementing CSS design principles, mobile-first responsive layouts, and intuitive structure aligned with client goals and user audience[cite: 1].

* **Typography**: Maximum of 2 font families establishing clear visual hierarchy[cite: 1].
* **Responsive Layout**: Mobile-first design adapting seamlessly via media queries across mobile, tablet, and desktop viewports[cite: 1].

1. **`index.html`**: Home page featuring welcome content, signature items, and audio fallbacks[cite: 1, 3].
2. **`products.html`**: Product catalog showcasing artisan breads, pastries, and custom cakes.
3. **`about.html`**: Brand story, sourcing philosophy, and team highlights[cite: 2].
4. **`contact.html`**: Contact form for pre-orders and general inquiries[cite: 1].

# ⚡ Part 2: Touchstone 4 - Interactivity and Client-Side Data

## 📌 عن المشروع (باللغة العربية)
هذا المشروع هو تطبيق عملي لشروط (**Touchstone 4: Interactivity and Client-Side Data**) لبرنامج تطوير الويب، مع الحفاظ على القواعد البصرية والتصميم المتجاوب المنجز في (**Touchstone 3**)[cite: 1]. يقدم المشروع موقعاً إلكترونياً متجاوباً وتفاعلياً لمخبز **North Star Bakery**[cite: 1, 2]. يركز العمل على تطبيق قواعد البرمجة بلغة **JavaScript**، وتفعيل ذاكرة المتصفح (`localStorage`)، والفحص المخصص للنماذج (Form Validation)[cite: 1].

### 🛠️ التقنيات المستخدمة:
* **HTML5**: لبناء هيكلية الصفحات المتعددة واستخدام العناصر الدلالية (`<picture>`, `<figure>`, `<form>`, `<fieldset>`)[cite: 1, 3, 4].
* **CSS3**: لتنسيق الألوان، الخطوط، واستخدام **Flexbox** مع **Media Queries** للتجاوب مع مختلف الشاشات[cite: 1].
* **JavaScript (ES6)**: لإضافة التفاعلية الديناميكية، إدارة هياكل البيانات (Arrays & Objects)، وفحص المدخلات[cite: 1, 6].
* **Browser LocalStorage**: للحفاظ على بيانات المفضلة واسم المستخدم عبر جلسات المتصفح[cite: 1, 6].
* **GitHub Pages**: لاستضافة المعاينة المباشرة للمشروع[cite: 1].

### 🎨 النظام البصري للتصميم (من Touchstone 3):
* **الألوان (Color Palette)**: استخدام نظام ألوان متناسق يعبر عن طابع المخابز الدافئ ويعزز التباين وسهولة القراءة[cite: 1].
* **الخطوط (Typography)**: استخدام خطين كحد أقصى لتسهيل التصفح السريع مع تحديد هرمية بصرية بوزن وحجم الخطوط[cite: 1].
* **التجاوب (Responsive Design)**: اتباع نهج *Mobile-First* لضمان عمل الموقع بكفاءة على جميع الشاشات[cite: 1].

### 📁 صفحات الموقع والتفاعلية:
1. **`index.html`**: الصفحة الرئيسية وتضم الترحيب، المنتجات المميزة، وتوافق الملفات الصوتية[cite: 1, 3].
2. **`products.html`**: قائمة المنتجات المصنفة وتتضمن ويدجت متتبع المفضلة التفاعلي (Interactive Favorites Tracker)[cite: 1, 5].
3. **`about.html`**: قصة المخبز ورؤية العمل وطاقم المخبز[cite: 2].
4. **`contact.html`**: صفحة التواصل والطلبات المسبقة المزودة بفحص جافاسكريبت لحقول الإدخال[cite: 1, 3, 6].

## 🚀 تحديثات المرحلة الرابعة (Touchstone 4 Updates)

في هذه المرحلة تم تحويل الموقع من صفحات استعراضية إلى تطبيق ويب تفاعلي بالكامل:

1. **متتبع المنتجات المفضلة التفاعلي (`products.html`)**:
   - إمكانية إضافة وإزالة المنتجات من قائمة المفضلة بنقرة زر بدون إعادة تحميل الصفحة[cite: 1, 5, 6].
   - تحديث العداد وزر الإضافة ديناميكياً باستخدام مصفوفة `userFavorites`[cite: 5, 6].

2. **حفظ البيانات في ذاكرة المتصفح (`localStorage`)**:
   - حفظ قائمة العناصر المفضلة تحت المفتاح `northStar_favorites` واسترجاعها تلقائياً عند فتح أو تحديث الصفحة[cite: 1, 6].
   - الحفظ التلقائي لاسم الزائر في نموذج الطلب المسبق تحت المفتاح `northStar_preorder_name`[cite: 3, 6].

3. **التحقق من صحة النموذج للجافاسكريبت (`contact.html`)**:
   - منع إرسال البيانات الخاطئة مع إظهار رسائل تنبيهية باللون الأحمر أسفل الحقول غير المكتملة[cite: 1, 3, 6, 7].
   - التحقق من الحد الأدنى لطول الاسم والتحقق من صيغة البريد الإلكتروني عبر (Regex)[cite: 3, 6].

## 📌 About The Project (English)
This project is a practical submission for **Touchstone 4: Interactivity and Client-Side Data** built upon the visual foundation of **Touchstone 3** in the Web Development program[cite: 1]. ### 📁 Included Pages & Interactive Features:
1. **`index.html`**: Home page featuring welcome content, signature items, and audio fallbacks[cite: 1, 3].

3. **`about.html`**: Brand story, sourcing philosophy, and team highlights[cite: 2].
4. **`contact.html`**: Pre-order form featuring client-side validation logic and error feedback[cite: 1, 3, 6].
