# 🥐 North Star Bakery - Touchstone 3 Project

مرحباً بك! هذا المشروع هو تطبيق عملي لواجب دراسي (**Touchstone 3: Visual Design and Responsive Layout**) لبرنامج تطوير الويب[cite: 1].

---

## 📌 عن المشروع (Project Overview)
يقدم هذا المشروع موقعاً إلكترونياً متجاوباً ومتناسقاً لمخبز **North Star Bakery**[cite: 1, 2]. يركز العمل على تطبيق قواعد التصميم المرئي (CSS)، وتنسيق الهيكل التجاوُبي (Responsive Layout)، وتنظيم العناصر بشكل يدعم تجربة المستخدم والأهداف الخاصة بالعميل[cite: 1].

---

## 🛠️ التقنيات المستخدمة (Technologies Used)
* **HTML5**: لبناء هيكلية الصفحات المتعددة واستخدام العناصر الدلالية (`<picture>`, `<figure>`, `<form>`, `<fieldset>`)[cite: 1, 3, 4].
* **CSS3**: لتنسيق الألوان، الخطوط، واستخدام **Flexbox** مع **Media Queries** للتجاوب مع مختلف الشاشات[cite: 1].
* **GitHub Pages**: لاستضافة المعاينة المباشرة للمشروع[cite: 1].

---

## 🎨 النظام البصري للتصميم (Design System)
* **الألوان (Color Palette)**: استخدام نظام ألوان متناسق يعبر عن طابع المخابز الدافئ ويعزز سهولة القراءة[cite: 1].
* **الخطوط (Typography)**: اعتماد خطوط واضحة للتصفح السريع مع تحديد هرمية بصرية بوزن وحجم الخطوط[cite: 1].
* **التجاوب (Responsive Design)**: اتباع نهج *Mobile-First* لضمان عمل الموقع بكفاءة على الشاشات الصغرى والكبرى[cite: 1].

---

## 📁 صفحات الموقع (Pages Included)
1. **`index.html`**: الصفحة الرئيسية وتعرض رسالة الترحيب والمنتجات المميزة وتسجيل صوتي[cite: 1, 3].
2. **`products.html`**: قائمة المنتجات المصنفة (خبيز حقيقي، حلويات، كعك مخصص).
3. **`about.html`**: قصة المخبز ورؤية العمل وطاقم المخبز.
4. **`contact.html`**: صفحة التواصل والاستفسارات المسبقة للطلبات[cite: 1].
