# 🥐 North Star Bakery - Touchstone 3 Project

## 📌 عن المشروع (باللغة العربية)
هذا المشروع هو تطبيق عملي لواجب دراسي (**Touchstone 3: Visual Design and Responsive Layout**) لبرنامج تطوير الويب[cite: 1]. يقدم المشروع موقعاً إلكترونياً متجاوباً ومتناسقاً لمخبز **North Star Bakery**[cite: 1, 2]. يركز العمل على تطبيق قواعد التصميم المرئي (CSS)، وتنسيق الهيكل التجاوُبي (Responsive Layout)، وتنظيم العناصر بشكل يدعم تجربة المستخدم والأهداف الخاصة بالعميل[cite: 1].

### 🛠️ التقنيات المستخدمة:
* **HTML5**: لبناء هيكلية الصفحات المتعددة واستخدام العناصر الدلالية (`<picture>`, `<figure>`, `<form>`, `<fieldset>`)[cite: 1, 3, 4].
* **CSS3**: لتنسيق الألوان، الخطوط، واستخدام **Flexbox** مع **Media Queries** للتجاوب مع مختلف الشاشات[cite: 1].
* **GitHub Pages**: لاستضافة المعاينة المباشرة للمشروع[cite: 1].

### 🎨 النظام البصري للتصميم:
* **الألوان (Color Palette)**: استخدام نظام ألوان متناسق يتكون من 2 إلى 4 ألوان تعبر عن طابع المخابز الدافئ وتعزز سهولة القراءة[cite: 1].
* **الخطوط (Typography)**: استخدام خطين كحد أقصى لتسهيل التصفح السريع مع تحديد هرمية بصرية بوزن وحجم الخطوط[cite: 1].
* **التجاوب (Responsive Design)**: اتباع نهج *Mobile-First* لضمان عمل الموقع بكفاءة على الشاشات الصغرى والكبرى[cite: 1].

### 📁 صفحات الموقع:
1. **`index.html`**: الصفحة الرئيسية وتضم الترحيب، المنتجات المميزة، وتوافق الملفات الصوتية[cite: 1, 3].
2. **`products.html`**: قائمة المنتجات المصنفة (خبيز حقيقي، حلويات، كعك مخصص).
3. **`about.html`**: قصة المخبز ورؤية العمل وطاقم المخبز.
4. **`contact.html`**: صفحة التواصل والاستفسارات المسبقة للطلبات[cite: 1].

## 📌 About The Project (English)
This project is a practical submission for **Touchstone 3: Visual Design and Responsive Layout** in the Web Development program[cite: 1]. It features a responsive and visually cohesive website for **North Star Bakery**[cite: 1, 2]. The project focuses on implementing CSS design principles, mobile-first responsive layouts, and intuitive structure aligned with client goals and user audience[cite: 1].

### 🛠️ Technologies Used:
* **HTML5**: Multi-page semantic markup incorporating `<picture>`, `<figure>`, `<form>`, and `<fieldset>` elements[cite: 1, 3, 4].
* **CSS3**: Custom styling using Flexbox, media queries, standard color variables, and typography rules[cite: 1].
* **GitHub Pages**: Live preview site deployment[cite: 1].

### 🎨 Visual Design System:
* **Color Palette**: 2–4 primary colors providing warm aesthetic and high text contrast[cite: 1].
* **Typography**: Maximum of 2 font families establishing clear visual hierarchy[cite: 1].
* **Responsive Layout**: Mobile-first design adapting seamlessly via media queries across mobile, tablet, and desktop viewports[cite: 1].

### 📁 Included Pages:
1. **`index.html`**: Home page featuring welcome content, signature items, and audio fallbacks[cite: 1, 3].
2. **`products.html`**: Product catalog showcasing artisan breads, pastries, and custom cakes.
3. **`about.html`**: Brand story, sourcing philosophy, and team highlights.
4. **`contact.html`**: Contact form for pre-orders and general inquiries[cite: 1].
